Website
=======

The files of the site <https://thiago-rissi.github.io/Mental-Rotation-Preparation/>: the theme settings ([_config.yml](_config.yml)), the colours ([assets/css/style.scss](assets/css/style.scss)) and the figures of the report.

The text of the report is the [README](../README.md) at the root of the repository. [pages.yml](../.github/workflows/pages.yml) copies it here as the home page before building the site.
