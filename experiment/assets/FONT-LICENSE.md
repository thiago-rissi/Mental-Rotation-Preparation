# Font

`Inconsolata.ttf` is the default font of goxpyriment (copied unchanged from
`assets_embed/Inconsolata.ttf` in goxpyriment v0.30.0). Inconsolata was designed
by Raph Levien and is distributed under the
[SIL Open Font License, Version 1.1](https://openfontlicense.org/open-font-license-official-text/),
which allows embedding it in, and redistributing it with, software.

It is a sans-serif (monospaced) face whose `G`, `J`, `R`, `2`, `5` and `7` are
all mirror-asymmetric, which is what the normal/backward judgement needs.
